# Matriz de verificación

Lista de control que el asistente recorre íntegramente. Cada ítem se responde con
**Cumple / No cumple / No aplica / No verificable**, y todo "No cumple" o "No verificable"
genera un hallazgo.

## I. Veracidad

| N.º | Control |
|---|---|
| V-01 | Cada cuerpo normativo citado existe con ese número y fecha. |
| V-02 | Cada artículo citado corresponde al tema para el que se invoca. |
| V-03 | Las citas presentadas como textuales (entre comillas o en bloque) son literales; las paráfrasis no se presentan como citas. |
| V-04 | Cada norma está vigente en la redacción citada (sin derogación, subrogación, reforma ni declaratoria de inconstitucionalidad posterior). |
| V-05 | En normas procesales, se aplica el régimen correcto según la fecha de inicio del proceso (especial atención: Código Judicial vs. Código Procesal Civil, Ley 402 de 2023). |
| V-06 | Cada fallo citado existe; tribunal, sala, fecha y número de registro coinciden. |
| V-07 | Cada fallo dice lo que el escrito le atribuye; no se presenta un *obiter* como *ratio decidendi*; no fue revocado ni superado. |
| V-08 | Cada tratado invocado está vigente para Panamá; ley aprobatoria correcta; sin reservas que afecten la cita. |
| V-09 | Cada hecho afirmado tiene respaldo en una prueba aportada o aducida, y la prueba dice lo que el escrito le atribuye. |
| V-10 | Números de resolución, expediente, cédula, RUC, finca, folio y fechas de notificación coinciden con los documentos aportados. |
| V-11 | Nombres y cargos de autoridades y partes son exactos (incluida la denominación oficial vigente de la entidad). |
| V-12 | Las cifras y cálculos (intereses, salarios, cuantía, plazos) son aritméticamente correctos. |

## II. Coherencia interna

| N.º | Control |
|---|---|
| H-01 | Cronología consistente: ninguna fecha posterior aparece como antecedente de otra anterior; ninguna fecha imposible. |
| H-02 | Mismo nombre, cédula y calidad de cada parte a lo largo del escrito. |
| H-03 | Montos idénticos entre hechos, pretensión, cuantía y anexos. |
| H-04 | Cifras en letras coinciden con cifras en números. |
| H-05 | Hechos numerados correlativamente, sin saltos ni duplicados. |
| H-06 | Remisiones internas ("véase el hecho quinto", "supra") apuntan al lugar correcto. |
| H-07 | Cada término jurídico conserva un mismo sentido (p. ej., "nulidad" vs. "anulabilidad"; "acto" vs. "resolución"). |
| H-08 | No hay argumentos mutuamente excluyentes, salvo planteados expresamente como principal y subsidiario. |
| H-09 | El acto impugnado se identifica igual en todo el escrito (número, fecha, emisor). |
| H-10 | Los anexos enumerados coinciden con los anexos efectivamente referidos en el cuerpo. |

## III. Congruencia

| N.º | Control |
|---|---|
| C-01 | Cada pretensión tiene al menos un hecho que la sostiene. |
| C-02 | Cada hecho relevante para una pretensión tiene prueba. |
| C-03 | Cada norma invocada se conecta con un hecho concreto y con una pretensión. |
| C-04 | Para cada norma que se dice infringida hay concepto de la infracción específico (no genérico ni por mera transcripción). |
| C-05 | La pretensión es de las que la vía procesal escogida permite obtener (p. ej., no pedir indemnización en una vía que no la admite). |
| C-06 | La autoridad destinataria es competente por materia, grado y territorio. |
| C-07 | Legitimación activa y pasiva acreditadas; poder suficiente del apoderado. |
| C-08 | Oportunidad: plazo de caducidad o prescripción, agotamiento previo de vía o recursos, según la vía. |
| C-09 | Cumplimiento de los requisitos formales del tipo de escrito (ver `requisitos-por-escrito.md`). |
| C-10 | Lo pedido en la parte petitoria es lo mismo que se anuncia en la introducción y en las conclusiones (sin ampliaciones ni reducciones tácitas). |
| C-11 | Las medidas cautelares o suspensiones solicitadas guardan relación con la pretensión principal y tienen fundamento propio. |
| C-12 | Las pruebas aducidas son conducentes y pertinentes para los hechos que se pretenden probar. |
